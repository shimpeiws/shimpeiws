# Shimpei Takamatsu

I'm a software developer in Tokyo, building tools for coding agents. My current interests are reproducible agent configurations, coding-agent evaluation, and autonomous development feedback loops.

## Open source

[**yuurei**](https://github.com/shimpeiws/yuurei) — A CLI for running Claude Code, Codex, and OpenCode with isolated configuration profiles, so I can compare setups without replacing my everyday global configuration. It records traces and logs for each run; isolation covers configuration and environment variables, rather than OS-level sandboxing.
